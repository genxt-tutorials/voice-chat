Voice Chat for LFM3-Omni

Talk to LFM3-Omni-2B, a free AI from Liquid AI, and hear it answer out loud, on your own PC. No graphics card needed. It's one HTML file that only talks to the model on your own computer.

Download voice-chat.html

21 KB. Works in Microsoft Edge or Google Chrome on Windows.

How to use it on Windows

  1. Right-click Start, open Terminal, and install llama.cpp:
    winget install llama.cpp
  2. Open a new Terminal and start the model. The first time, it downloads about 1.4 GB. When it says listening, it's ready. Keep this window open.
    llama serve -hf LiquidAI/LFM3-Omni-2B-GGUF:Q4_K_M --reasoning off --temp 0
  3. Open the downloaded voice-chat.html, press the microphone, allow it, and just talk.

Good to know

  • It sends your turn after you stop talking for a moment, and the answer started about two seconds later on our test PC (no graphics card).
  • Settings on the page: a female or male voice, the instructions the AI follows, and the server address (llama.cpp's default is 127.0.0.1:9931).
  • You can also type a message, and save any spoken answer as a WAV file.
  • The model speaks 18 languages. Indian languages such as Hindi are not among them.
  • For photos and videos, use llama.cpp's own chat page at http://127.0.0.1:9931. It answers in text.
